# Tutorials

Put each tutorial in the `posts` folder as a Markdown file.

Start from `templates/new-post.md` in the repository root, or fill the same fields at the unlisted `/post-builder/` page and download the file. That page does not upload or publish. See `POST_BUILDER.md`. Do not publish the template file by leaving it here under a half-finished name unless `draft` is still `true`.

If this GitHub repository is public, every file in this folder is public, including drafts.
